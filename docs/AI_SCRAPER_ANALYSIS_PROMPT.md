### 4. Надійність, обхід блокувань та дедуплікація (Robustness & Anti-Bot)
4.1. **Робота з Cloudflare, Akamai, Datadome без порушення правил**:
     - Ротація User-Agent, правильні HTTP/2 заголовки, підтримка сесійних cookies, обробка рейт-лімітів (Exponential Backoff з jitter).
     - Використання публічних API каталогів та мобільних endpoints, які зазвичай не закриті агресивним WAF.
4.2. **Дедуплікація та запобігання спаму алертів**:
     - Створення стійкого детермінованого `fingerprint_id` (наприклад, `sha256(store_id + normalized_title + price + valid_dates)`).
     - Механізм Baseline: як гарантувати, що після перезапуску бота, оновлення коду чи відновлення після збою користувачам не надійдуть сотні старих акцій як "нові".
4.3. **Моніторинг працездатності та Failover**:
     - Якщо один скрапер зламався через зміну структури сайту, як ізолювати помилку, зберегти працездатність інших 9+ магазинів і надіслати алерт адміністратору?
