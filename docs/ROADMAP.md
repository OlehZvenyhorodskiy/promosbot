# Belgium Promos Bot — Project Roadmap & Development Plan

Дорожня карта розвитку проєкту, архітектурних оновлень та інтеграції з GitHub.

## 1. Поточний стан проєкту (Baseline)

- **Telegram Bot**: реалізовано на `aiogram 3` (команди `/start`, `/promos`, `/search`, `/stores`, `/categories`, `/favorites`, `/settings`, `/test_promo`, `/help`).
- **Скрапери**:
  - `Aldi`: витягнення з вбудованого Algolia JSON у `__NEXT_DATA__`.
  - `Colruyt`: селектори промо-карток HTML (`.action-card`, `.promo-card`).
  - `Carrefour`: парсинг схем `JSON-LD` (`Product`, `offers`) з HTML-фолбеком.
  - `GenericRetailerScraper`: базовий HTTP/HTML парсер цін та бейджів для інших 7 мереж.
  - `BrowserRetailerScraper`: Playwright Chromium семафорний фолбек для клієнтського рендерингу (CSR).
  - `NewsletterParser`: прийом вхідних вебхуків розсилок (`/api/v1/inbound-newsletter`).
  - `GeminiFolderParser`: прототип розпізнавання сторінок брошур через `gemini-2.5-flash`.
- **База даних**: SQLite (`src/db/repository.py`) з дедуплікацією за `external_id`.
- **Тести**: 10 юніт-тестів на сховище, пошук, i18n, скрапери та веб-сервер.

## 2. Етапи розвитку та заплановані фічі (Milestones)

### Milestone 0: Стабілізація ядра та дедуплікація за fingerprint (Виконано ✅)
- [x] **Детермінований `generate_fingerprint()`**: очищення ваги/пакувань та генерація 24-символьного SHA-256 хешу (`src/scrapers/base.py`).
- [x] **Розширена модель `PromoItem`**: підтримка полів для буклетів, брендів, типів знижок та підрахунку відсотка економії (`src/scrapers/models.py`).
- [x] **Безшовна міграція SQLite**: автоматичне додавання стовпця `fingerprint` та `UNIQUE` індексу без втрати даних користувачів (`src/db/database.py`).
- [x] **Дедуплікація в сховищі**: оновлення існуючих акцій без помилкових повторних алертів користувачам (`src/db/repository.py`).
- [x] **Ізоляція збоїв (Circuit Breaker)**: автоматичне відсікання завислих скраперів із відновленням через 300 секунд (`src/utils/circuit_breaker.py`, `src/scrapers/engine.py`).
- [x] **Юніт-тести**: 16 з 16 тестів проходять (нормалізація, хешування, стан вимикача збоїв, веб-сервер, дедуплікація).

### Milestone 1: Повноцінний скрапер усіх брошур та буклетів (Folders Engine) (Виконано ✅)
- [x] **Підключення платформ цифрових каталогів**:
  - Інтеграція з Publitas API (JSON метадані з хотспотами товарів, знижок та посилань для мереж на кшталт Albert Heijn, Aldi, Carrefour, Colruyt).
  - Скрапінг агрегаторів бельгійських каталогів (Tiendeo.be) з мапінгом slug супермаркетів.
- [x] **Гібридний обробник PDF/векторного шару**:
  - Векторне витягнення текстового шару через `pypdf`/`pdfplumber` без втрати якості та без витрат API токенів.
  - Оркестратор `LeafletOrchestrator` для паралельного збору брошур та збереження з типом `source_type="leaflet"`.
- [x] **Telegram-інтерфейс для буклетів**:
  - Окремий режим перегляду активних щотижневих буклетів (`/folders`) з кнопками прямих посилань та inline-переглядом акцій з брошур.

### Milestone 2: Розширення списку магазинів та джерел акцій (Виконано ✅)
- [x] **Нові бельгійські мережі**:

## 3. GitHub Workflow

1. **Гілки**:
   - `main`: стабільна робоча версія, що розгортається на сервер.
   - `feature/<назва>`: нова функціональність (наприклад, `feature/publitas-folders-engine`).
   - `fix/<назва>`: виправлення помилок або адаптація до зміни верстки магазину.
2. **Контроль якості**:
   - Автоматичний запуск тестів через GitHub Actions (`.github/workflows/ci.yml`) при кожному push та PR.
   - Обов'язкова локальна перевірка: `.venv\Scripts\python.exe -m pytest -q`.
3. **Безпека секретів**:
   - Жодних секретних ключів, токенів чи локальних БД у репозиторії.
